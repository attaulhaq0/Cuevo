# Portfolio and Learning Journey

## Purpose

Make student work meaningful over time.

## Evidence-based portfolio

Portfolio items may link to:
- course
- activity
- assessment
- curriculum reference
- reflection
- achievement
- project
- intervention outcome

## Student controls

Student can:
- select work
- add reflection
- explain what they learned
- organize selected work
- request teacher feedback

## Teacher controls

Teacher can:
- recommend work
- comment
- mark featured evidence
- connect to learning objectives

## Parent view

Only school-approved portfolio items are visible.

## Intelligence

AI may help draft:
- reflection prompts
- portfolio summaries

AI must not fabricate achievement.

## MVP

Show:
- selected work
- linked curriculum/evidence
- learner reflection
- teacher feedback
