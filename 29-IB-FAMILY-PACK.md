## PYP

Public IB information describes PYP as:
- ages approximately 3–12
- inquiry-based
- transdisciplinary
- student-centered
- conceptual
- a framework where students are agents/partners in learning

The engine therefore must support:
- transdisciplinary units
- programme of inquiry representation
- agency/reflection
- subject/domain references
- evidence-rich projects

## MYP

Public IB information describes:
- five-year programme
- eight subject groups
- flexibility in final years
- school-based assessment
- criteria/objectives
- personal project in final year
- optional external eAssessment

The assessment adapter must support criterion-based subject assessment rather than assuming percentage grading.

## DP

Public IB information describes:
- six subject groups
- DP core
- TOK
- Extended Essay
- CAS
- HL/SL
- internal/external assessment
- course grades 1–7
- diploma-level points calculation and award conditions

Represent:
- course result
- core components
- assessment components
- HL/SL
- diploma aggregation
as separate layers.

## CP

Public IB information describes:
- minimum DP courses
- CP core
- career-related study
- internal/external assessment
- reflective project and other core components

Do not collapse CP into DP.
