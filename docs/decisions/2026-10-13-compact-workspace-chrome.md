# Compact authenticated workspace chrome

The founder requested the13October refinement after reviewing the current app: keep the main navigation, move authenticated English/Arabic controls into Profile, remove repeated visible section labels and the Admin school-name card, replace Student Home refresh text panels with one icon, place current School heading/filter controls horizontally, and remove generic About disclosures after checking their purpose. This supersedes only the redundant presentation portions of the5October heading decision; record identity, source authority, semantic headings and focused navigation remain.

The existing UI navigation provider exposes the currently supplied workspace label and a focused-only compaction opt-in. A feature may mark its own section title as navigation context only where it actually renders that subsection in the existing navigation host. The heading compacts only an exactly matching plain-string workspace/section label. A different selected record title stays visible. Before a subsection host/source is ready, its section heading stays visible. Useful child/class/course captions, native errors, descriptions, source warnings and actions remain with their owners. One semantic h1 remains in the current content; deliberate navigation focuses the visible main landmark when that h1 is compact. This is a presentation check, not an authorization or selection registry.

Authenticated LanguageSwitch moves into the existing native Profile popover once, with full English/Arabic labels, existing preference cookie and keyboard focus. Sign-in retains its language controls. The same session, actor, generation, draft and command owners remain. The global navbar on Home and focused workspace/section controls elsewhere remain.

Student Home supplies one IconButton with its original refresh callback at the logical inline end. Current unavailable/partial/error text remains readable without its former large framed recovery row. Existing primary task actions remain; only repeated identical refresh actions are removed. The old runtime Quiet presentation toggle targeted elements no longer rendered and had no visible effect; it is removed while Hide/Show Foxi and reduced-motion behavior remain. The Admin card repeating the already visible school name is removed, while actual school facts and missing-name guidance remain.

School's actual My school day/context and labelled native date use one existing cuevo-section-header row, with responsive wrapping. Staff retains current class/date, timezone, source completeness and original pending-command locks. Parent's current-child calendar branch is unchanged. No field, query, role, relationship, command or date authority is moved into Shell.

The former generic About footer repeated broad feature descriptions. The source audit confirms essential school access, current source, curriculum/rights, academic/Parent publication, restricted-record safeguarding and account support/session explanations remain beside their actual decisions or in Account/Access. The unused Account EnvironmentDetails module is removed with its test/styles. Source/provenance disclosures and record-specific help remain. There is no blanket removal of contextual instructions or warnings.

Verify exact matching and nonmatching titles, no-host/loading, Home/standalone, all roles, English/Arabic, desktop/mobile, native focus/Back/Profile/Escape, tooltip, language persistence, retained drafts/original commands, minimum targets, source errors and horizontal reflow. Meaningful controlled browser checks and a build do not establish all connected or hosted acceptance. The Student bottom-panel concepts and richer period-specific recognition are separate proposals awaiting selection; this change adds no points, achievements, data or filler.

Exact identity guard: workspaceTitle is an explicit generic-workspace opt-in, default false. The section navigationTitle applies only with a mounted focused host and exact plain-string match. Human record names that happen to equal a workspace name remain visible, and every source caption is retained even when its text equals a workspace label. Independent review found these two collisions; meaningful regression checks preserve them.
