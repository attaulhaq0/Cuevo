# Portfolio organization and exact feedback requests

Source16 explicitly allows students to organize selected work and request teacher feedback. Existing portfolio evidence, reflection revisions and human reviews remain the authoritative identities. This increment adds learner-owned named collections, append-only placement revisions and a request pinned to the exact current reflection. It copies no source evidence, grade, parent approval or submitted work.

Collection names are unique per learner after whitespace/case normalization. Bounded collection reads use current placement order and reject changed cursors or exhausted inaccessible-source scans. All organization commands repeat current portfolio/school/learner/source scope after waits and before original-key replay. Requests enter only the current authorized teacher/admin queue with exact numeric/rubric source identity and marking relationship; current source loss hides pending work. Parents/coordinators receive no queue.

Requested review returns the exact title/reflection, native result and authorized submitted TEXT/FILE work where applicable. The browser validates request/item/revision/learner identity, escapes text and requires selected document downloads before the explicit human confirmation. Existing immutable review records resolve the request. Reviewed reflections require a new learner revision before another request, while retries with the original key recover the original receipt. Private FORCE RLS tables and purpose-granted helpers prevent direct browser/Data API access; source-validated transactional outbox events remain auditable without copying answer bodies into event metadata.
