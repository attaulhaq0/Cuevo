# Period objective planning and recorded coverage

**Goal:** Teachers explicitly plan approved course objectives for a configured school reporting period, record a taught lesson and attach exact assessments. Coordinators can then see the declared planned denominator and separate taught/assessed/evidence facts for their current class/course/period. No official curriculum completeness, normalized attainment or inferred teaching claim is produced.

**Sources:** Product13 teacher planning;18 teacher outcome/coordinator curriculum coverage and missing/pending/verified distinctions;37 teacher Planning/coordinator Curriculum coverage/evidence gaps;05 immutable programme/reference/course/assessment hierarchy;04 evidence provenance;17 native results;39 current object scope;83 scoped MVP numeric/rubric evidence. Current school report periods are immutable school-owned sources; the school maintenance owner is editing their workflow, so reuse those persisted records/public API without changes to school source logic.

**Denominator:** A current teacher/admin explicitly plans one approved course objective for one report period, with a human reason and confirmation. Store an immutable school/course/reference/period planning record rather than treating every pack objective as required teaching. The planned objective must be either an exact immutable course-approved programme mapping or an approved unbound School Custom objective. The period's term academic year must match the course class academic year; no source date or grade boundary is guessed. New source versions never rewrite existing plans.

**Recorded teaching:** Record a separate immutable teacher declaration that the planned objective was taught in one actual lesson owned by that same course, with the teacher-supplied taught date within the selected period and a concise source note. Label this “Teacher recorded taught lesson”; learner activity completion is not proof that the class was taught. Keep lesson/objective/source identity and author audit. No AI declaration or attendance inference is permitted.

**Period recovery:** The plan pins the current school period revision/name/date/term snapshot. Maintenance→course locking serializes that choice with school edits. Future UTC dates cannot be recorded as already taught. If the school changes the period, staff explicitly review/replan to a new immutable plan revision; the latest plan alone supplies this objective's declared denominator. Prior taught/task/evidence records stay attached to their original plan and are never silently carried into the new dates. CANCELLED periods require school recovery before new planning links. Duplicate historical enrollment rows are collapsed by learner identity; numeric/rubric evidence both require exact learner/source/reference-version validation.

**Assessment inclusion:** Explicitly attach a current published assessment in that exact course and approved objective to the plan. This declares the task belongs to the plan's period; do not infer period membership from missing due dates or a later release timestamp. Used assessment/objective mappings remain fixed. Assessment presence means a planned task exists; released native result/evidence facts are distinct. Expose actual task/due/release times and the declared inclusion boundary in source detail, never claim every included result occurred inside the period.

**Coverage read:** Private current staff class/course/period page with at most25 planned objectives and a cursor. Return total declared planned objective count, exact taught-record count, included assessment count, current authorized learner denominator and separately distinct learners with released exact current native results/evidence for each plan objective. Count only current learner/class/programme/member sources and exact assessment/reference/evidence identities. Numeric zero remains real native evidence, rubric criterion results remain native. Display missing teaching/assessment/evidence as recorded absence against this declared plan; no plan means denominator UNKNOWN/NOT_ESTABLISHED. A complete declared plan does not prove official curriculum coverage. Do not display an invented percentage or map this to academic attainment.

**Authorization and reliability:** Teacher/admin commands check curriculum/assessment/learning current tenant/entitlement/session/class/course/objective/period/lesson/assessment scope before replay; coordinator/admin current class access reads coverage, teacher reads owned course. Important planning/teaching/task links are idempotent, immutable, auditable and transactional-outbox-backed. Lock course then plan/source in stable order; no browser raw grants or worker academic authority. Invalid/foreign/year-mismatch/stale/objective-version/current-learner cases deny without records or receipts.

**UI:** Curriculum owns the course/period objective plan and coordinator coverage review, reusing course-approved choice model and school period parser/public API. Teacher/admin Planning action uses actual objective/lesson/assessment selections, saved descriptions and explicit confirmation. Read screens show human course/class/programme/year/period names and declared-plan limits; unknown source context supplies coordinator review. Bounded choices, EN/AR/RTL, mobile, keyboard, reduced motion, response/session cancellation and original-key retry use existing shared infrastructure. Native evidence opens academic public UI only after current authority.
