No backup/restore drill—including private Storage objects—two-worker contention stress, sustained lease-expiry recovery or final exact-source deployment verification was found. Previous CI passes must be attributed only to their commit. Current pending CI is not a passing release result.
- **Threat/design evidence:** design tokens, the security threat matrix, and saved foundation threat model/ERD exist in docs/architecture. They require updates for the improvement/community/final implemented boundaries. Complete API schema/generated-client coverage is not yet evidenced; state/list and some academic single-response OpenAPI metadata are explicitly incomplete.
- **All states/all roles:** existing responsive/Arabic/axe checks cover current journeys. New features do not inherit earlier screen checks.

## Synthetic seed and fixture gap

The committed seed matches 77's population: one admin, two coordinators, eight teachers, sixty students, sixty parents, four year groups, six classes and eight subjects, plus the isolation tenant. It establishes memberships, relationships, an approved synthetic school objective and a synthetic development window. It does **not** seed reproducible learner archetype A–G learning histories: high result/inconsistent practice, low result/high recorded effort, decline, missing work, successful intervention, inconclusive intervention, or alternate programme assignment. Runtime tests create useful random-ID happy paths, but they are not the deterministic clean demo/evaluation fixtures required by 77/78.

Add explicit source-linked synthetic history fixtures using configured school-custom criteria and neutral observations. Strong/weak/decline terms need declared synthetic comparison policies; do not silently invent official thresholds or causal conclusions. Keep no-work/missing results distinct from zero. Include successful and inconclusive outcomes, and programme diversity through configuration rather than core branches.
