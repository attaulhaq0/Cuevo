## What works

The standalone school foundation covers five-role Auth, current memberships/guardian/class/programme relationships, academic years/terms/year groups/subjects, attendance corrections, timetable/calendar/report periods and explicit school policy. Teachers publish courses, units, lessons, activities, assignments and immutable quiz versions. Students save private drafts, submit, receive teacher feedback and resubmit source-linked revisions. Quiz checking remains CHECKED_NOT_GRADED.

Numeric and teacher-defined rubric marking preserve their native models, immutable source versions, release/correction history, evidence provenance and explicit parent approval. Reports and portfolio retain exact source/evidence/reference/policy/revision/actor/time and never invent a normalized grade. Current role homes and class evidence views show separate academic, observed action, support and outcome records with explicit unknown coverage.

The integrated loop works: source learning → assessment → released evidence → restricted outbox worker → independent learner-state dimensions and factual signals → contextual fixture orchestration → grounded proposal → separate human approve/edit/reject → differentiated teacher-reviewed practice → student completion → compatible reassessment → measured native change. A–G deterministic learners demonstrate high/low native values, recorded practice/reflection, decline, missing work, improved/unchanged support outcomes and another programme. Facts, missing records and interpretation remain separate; outcomes do not claim causation or learner traits.

Community uses current class/teacher-group scope, narrow rosters, safe replies/reactions, report/hide/restriction/audit, approved announcements and in-app notifications. Private Realtime carries minimal invalidations and content is refetched through the authorized API. Private files use staged512KiB bounds, type/signature checks, SHA256 readback, current authorized download and retirement. Portfolio parent visibility points to an exact reviewed revision and remains revocable after learner edits. XP/achievements derive approved observed practice/revision/reflection, with period/source deduplication and opt-in alias-only class boards.

English/Arabic RTL is verified across all five roles and permitted major surfaces/read tabs. Real keyboard Tab/Enter focus, labels/AX semantics, WCAG2.2AA axe checks, five viewport sizes,200% zoom-equivalent layout reflow, reduced motion, form errors, offline/reconnect and denied/unavailable recovery are exercised. Responsive navigation focus and draft/refetch races were repaired from actual failures.

## Security and recovery

Authorization checks current tenant, entitlement, role, session, relationship, class/programme/object/source before new actions and replay. Runtime roles are non-owner/non-BYPASSRLS with explicit private grants and forced RLS. Grade release, reference mapping and access authority stay outside AI. Important commands retain fingerprints, original-key uncertain receipt recovery, audit and transactional outbox. Stored insight disclosure reauthorizes every saved result/observation/support/outcome/option; new authorized context does not falsely revoke old source access, and now-denied sources fail closed. Metrics preserve separate denominators and unknown unobserved safety rates.

Actual private WebSocket peer/parent/foreign/public and revoked session/roster joins are denied. Restored scratch data is exercised through the restricted API role, not just compared by an owner connection. Telemetry exposes fixed route/status/transaction/queue timing rather than child content, answers, prompts, raw errors or credentials. No live PostHog capture/session replay is configured.

Production regional/data residency/contracts, school/privacy/retention policy, production restore/alerts and customer approval remain separate prerequisites. File checks do not constitute malware-scanning certification. Reports are current native pages with unknown overall coverage, not official transcripts. Manual screen-reader listening, literal browser zoom gestures and non-Chromium compatibility remain unverified; automated AX/reflow evidence is scoped honestly.

The architecture remains Next.js16 → NestJS/Fastify domain modules → private PostgreSQL/Supabase → transactional outbox → restricted worker. No microservices or duplicate backend were introduced. Root Markdown and domain/feature/public-surface rules are enforced for people and agents. Product specifications stay under docs/product with the task context map/index/registry; generated dependencies, credentials, snapshots and reports stay ignored.
