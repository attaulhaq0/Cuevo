## Permitted exact-input reuse

All verdicts are created privately during this one read for the fixed verified actor, school, role and authorization context. Their inputs must come from persisted candidate/run/detail source rows. Caller-supplied JSON, arbitrary verdicts, persistent cache, TTL, module global state or previous-request reuse are not authorized. The map/helper receives no runtime/Data API grant. Missing key means denied/unknown, never true.
