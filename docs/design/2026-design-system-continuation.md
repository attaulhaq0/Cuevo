Its semantic light tokens and component stories are implemented. Authentication's responsive/Arabic/zoom verification is recorded in the [QA report](../reports/2026-10-01-auth-design-qa.md).

Dark/System theme persistence, pre-paint theme resolution, density/material/layering tokens, shared dialog/command/input/select/tabs/table/state anatomy, global command header, command home and mobile dock are not implemented. Current tables/forms/feature panels must migrate through their existing owners. No customer chart or global object-search backend is established by a navigation mockup.
