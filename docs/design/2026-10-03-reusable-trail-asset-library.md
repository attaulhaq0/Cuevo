## Content and output contract

The additional icon catalog covers learning, creative work, staff planning, assessment formats, academic record/source handling, curriculum configuration, communication, operations, safety, recovery and optional progression presentation. Each entry has a distinct intended metaphor, stable versioned identifier, category, source prompt/reference, exact source and derivative hash, intrinsic dimensions, usage constraints and static fallback. Labels remain localized HTML; images contain no invented school facts or primary text.

The 200 poses use 50 authored gestures/prop/state/cosmetic variants per character. These are distinct drawings, not 200 different mascots or relabeled copies. Physical costume candidates do not create ownership, prices, grants or learning entitlements. Confirmed-save and milestone art appears only alongside an independently confirmed current-scope receipt; art cannot award points or decide grades.

Deliver each foreground asset as a real alpha-channel RGBA PNG, plus an optimized WebP where reviewed. Preserve opaque provider originals and prompts as provenance; an original pink matte is not a transparent deliverable. Extract whole measured cells, remove only the matte, preserve authored violet/cyan/skin/fur, inspect light/dark edges and normalize optical size with padding. Do not crop subject parts to satisfy a requested margin that the generator missed. Material backgrounds remain backgrounds; where alpha overlay variants are needed, derive them deliberately rather than erase meaningful scene content.

Utility PNG exports have 24/32/48/64/96/128/256 dimensions and deliberate light/dark foreground colors. Dimensional icons use native master plus 24/32/48/64/96/128/192/256/512 padded canvases. Characters use native master plus 64/96/128/192/256/384/512/768 canvases. Record actual art bounds separately from canvas size. Create 3840×2160 presentation compositions and large transparent raster derivatives only with an explicit upscale label; SVG utility geometry scales directly. Web runtime continues to load the smallest accepted readable size. Source resolution and resampling never become a native-4K fidelity claim.

Optional self-contained SVG motion exports embed the exact PNG. They are raster-backed presentation effects, not vectorized character anatomy or native Sora motion. One short reveal/disclosure/acknowledgment/settling effect uses the shared motion meaning and a static reduced-motion equivalent. No automatic looping, sound, emotional pressure or animation-dependent status. Richer Sora character actions retain source video, reviewed samples and posters. Existing Sora sources are 1280×720; 1920×1080 masters are disclosed upscales. PNG frames and transparency require separate processing and review, not a misleading transparent-video claim.
