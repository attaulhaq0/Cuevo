# Build / Do Not Build Rules

## Build now

- foundational SIS context
- practical LMS/LXP
- real assessment/gradebook
- evidence provenance
- learner state
- small Habit/Learner Development engine
- deterministic signals
- agentic Intelligence Orchestrator
- human-approved recommendation
- personalized intervention
- reassessment/outcome measurement
- basic community/social layer
- gamification
- parent view
- English/Arabic responsive UX
- security and audit

## Architecture-ready but defer broad implementation

- complete Cambridge catalogue
- complete IB PYP/MYP/DP/CP
- all England subjects
- Pakistan full catalogue/provincial overlays
- deep Qatar regulatory packs
- QNSA/BSO/CIS full workspaces
- full admissions/finance/HR/transport
- advanced AI tutors
- enterprise integration platform

## Never build

- single student "quality" score
- psychological diagnosis from learning telemetry
- AI-controlled grade release
- automatic accreditation claim
- public child social network
- cross-school child messaging
- curriculum rules inferred from an LLM
- hidden authorization based on UI visibility
- hard-coded customer-specific curriculum branches

## Junior-developer safety

When unsure, do not improvise an architecture change.

Create a short ADR, mark the decision as OPEN, and preserve the existing invariant.
