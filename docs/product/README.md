# Cuevo product context

This is the canonical home of Cuevo's complete product specifications. E Deviser is the company. The 89 numbered sources retain their IDs, requirements, versions and academic uncertainty; moving them does not approve a curriculum pack or change product behavior.

Use [context-map.md](context-map.md) for the task reading guide, [index.md](index.md) for every source, and [registry.json](registry.json) for machine-readable IDs, current paths and original/current hashes.

[Original manifest](history/original-manifest.json) records the original FINAL-2026-10-01 pack metadata and former naming. It is historical evidence, not the current path registry. [Earlier product brief](history/source-readme.md) and [earlier starting brief](history/source-start-here.md) preserve the full initial context; current root README/START-HERE and this context map supersede their old file-location and repeated-reading instructions.

Specifications govern intent. [Implementation status](../implementation-status.md), reports and plans describe evidence/work, not new authoritative rules. Official curriculum snapshots, known rights and academic sign-off remain separately required. Stored documents are discoverable context, not automatically loaded model context; agents must explicitly read what applies.
