# Reporting, Transcripts and Parent Reports

## Reporting layers

### Student
- current progress
- learning evidence
- teacher comments
- development summary

### Parent
- school-approved child progress
- attendance where approved
- selected work
- teacher communication

### Teacher
- class progress
- outcome coverage
- intervention status

### Coordinator
- department/year analysis
- evidence gaps
- intervention outcomes
- curriculum coverage

### Admin
- school-level operational/academic summary

## Native curriculum reporting

Reports use the active programme's reporting model.

Do not convert every curriculum to one generic percentage report.

## Data integrity

A report must distinguish:
- missing
- not assessed
- not applicable
- pending
- verified

Never treat missing as zero.

## AI-generated reports

AI may draft narrative text only from approved evidence.

Teacher/authorized reviewer must approve customer-facing report narratives.

## Transcript

Transcript schema retains:
- programme
- course
- native result
- normalized result if available
- date
- assessment context
- institution
- version
