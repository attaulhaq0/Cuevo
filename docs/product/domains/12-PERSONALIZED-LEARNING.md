# Personalized Learning

## Principle

Personalization changes the learner’s path through approved learning, not the authoritative curriculum.

## Pipeline

```text
Curriculum objective
 ↓
Learner state
 ↓
Available learning options
 ↓
Personalization policy
 ↓
Recommended next experience
 ↓
Student/teacher decision
 ↓
Learning activity
 ↓
New evidence
```

## Personalization inputs

- mastery/attainment evidence
- misconceptions/weak areas when supported by evidence
- activity history
- previous intervention outcomes
- learner-selected preference
- current course context
- teacher constraints

Optional post-MVP:
- accessibility preferences
- pace preferences
- language preference
- demonstrated modality preference

## Outputs

- scaffold
- worked example
- targeted practice
- prerequisite review
- extension
- reflection prompt
- differentiated resource
- short reassessment

## Safety

Do not personalize based on:
- protected traits
- inferred mental state
- personality diagnosis
- family income
- sensitive family data

## Teacher control

Teacher can:
- accept
- edit
- dismiss
- create own intervention

Student can:
- see why a recommendation appears where appropriate
- ask for help
- choose among school-approved options

## MVP

Implement:
- one targeted intervention activity
- one differentiated practice path
- one reassessment

Do not build a full adaptive learning engine yet.
