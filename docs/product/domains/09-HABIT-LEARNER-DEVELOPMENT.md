# Habit / Learner Development Engine

## Purpose

Model observable learning behaviours and support healthy learning routines.

It is not a behavior surveillance engine and not a character judgement system.

## MVP dimensions

- Practice
- Revision
- Reflection

Post-MVP:
- planning
- persistence
- help-seeking
- self-assessment
- collaboration
- organization

## Pipeline

```text
Learning Event
 ↓
Habit Observation
 ↓
Pattern calculation
 ↓
Habit Signal
 ↓
Learner feedback
 ↓
Optional recognition/XP
```

## Observation examples

- practice_completed
- revision_after_feedback
- reflection_submitted
- goal_reviewed

## Pattern examples

```text
“4 practice sessions in 14 days.”
“2 revisions followed teacher feedback.”
“Reflection activity occurred 3 times this term.”
```

Use neutral language.

## Do not infer

Never infer:
- laziness
- intelligence
- personality
- mental state
- family situation
- motivation as a fixed trait

## Gamification

XP can be granted for approved behaviors:
- completing practice
- revising after feedback
- reflection streak
- helpful peer contribution

XP must not directly determine academic grades.

## Leaderboard

MVP leaderboard:
- school-controlled
- opt-in
- class scoped
- based on learning-behaviour points
- no grades shown
- ability to hide from leaderboard
- no punitive ranking
- tie-safe
- resettable by term/period

Alternative UI:
personal progress first; class challenge second.

## Habit privacy

Teachers may see signals for their students according to policy.

Parents see only school-approved summaries.

Students see their own detailed signals and goals.

## Future

Habit Engine can become a broader Learner Development Engine with goals, milestones, reflection and self-regulated learning.
