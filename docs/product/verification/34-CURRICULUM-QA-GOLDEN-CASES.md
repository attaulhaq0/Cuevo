# Curriculum QA and Golden Cases

## Goal

Prove that each pack behaves correctly, not merely that its data exists.

## Golden case categories

1. create course
2. assign curriculum
3. create assessment
4. attach native academic reference
5. mark assessment
6. store native result
7. link evidence
8. calculate/record attainment
9. report result
10. student view
11. parent view
12. invalid assessment
13. version mismatch
14. missing evidence
15. denied access
16. superseded version
17. migration replay

## Cambridge cases

- IGCSE subject with one assessment model
- IGCSE subject with coursework/practical/oral component where applicable
- native grade preservation
- exam series metadata

## England cases

- KS1 reference
- KS2 reference
- KS3 reference
- KS4 reference
- subject/grade/year mismatch rejection

## IB future cases

- MYP criterion-based assessment
- DP HL/SL
- DP 1–7 course grade
- DP core
- CP core

## Pakistan future cases

- versioned national reference
- rationalized grade 9–12 subject
- local/provincial overlay

## Qatar cases

- jurisdiction requirement mapped to a British programme
- local subject requirement surfaced without changing core curriculum identity

## Acceptance

No pack reaches CUSTOMER_READY until its required golden cases pass.
