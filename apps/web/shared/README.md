# Shared web infrastructure

The existing native continuation button carries its current API cursor in a nonvisible `data-page-cursor` attribute. Browser journeys can distinguish a committed next page from the previous button without relying on a fleeting loading frame. The cursor changes with the existing query snapshot; it is not a human label or authorization input, and labels, pending state, request callbacks and terminal behavior remain unchanged. `components/test/load-more.test.ts` verifies the current attribute and English/Arabic/pending/terminal presentation.

Shared `LearningError` uses `WorkspaceState` while retaining exact localized error/uncertain-original-request text, alert semantics and closed support reference. It creates no automatic retry. `LoadMore` presents an available continuation or its actual failure, with no detached terminal label or empty reserved row when all pages are loaded. Source owners continue to distinguish current empty, partial, failed and unknown data; silence from the pagination control is not a complete-source or zero-error claim.

Paginated continuation settlement releases the in-flight guard before publishing the current settled page/error, so an owner can safely request the next current page after React commits. Final cleanup checks the exact request controller as well as the frame before releasing that guard; an older request cannot unlock a newer continuation. Current frame admission, cancellation, page accumulation and original commands remain unchanged. The actual Learning30-page recovery regression and existing held-response `tests/e2e/query-frame.spec.ts` cover continuation and stale-frame behavior without services or database writes.

`hooks/query-frame.ts` gives single and paginated protected reads one private in-memory frame for API/token/actor/school/role/access generation/status/online/path/refresh. A changed frame returns empty current data and cursors before effects or a new response can render; disabled/null sources do not read. Each read passes its originating frame admission predicate to the shared request, so obsolete refusals and diagnostics cannot clear current drafts or revalidate access even before passive cancellation. Late successes cannot restore rows. Request/response callbacks use current refs so ordinary callback/locale rerenders do not reset a stable source; item parser identity remains an explicit dependency. Ordinary commands retain their current authority/signal guards; no command journal, feature selection or unsent form is remounted or resubmitted. Pure frame tests live in `shared/hooks/test`, and the network-free actual React held-response browser regression is `tests/e2e/query-frame.spec.ts`, including live-signal admission and same-authority continuation cases; authorization remains API/database owned.

Providers exposes a general `restoreSession` helper for an actual provider access/refresh pair. It delegates only to the existing memory-only Auth client setSession; normal Auth events clear prior scopes and fetch current membership. It accepts no role, school or membership projection and imports no feature/server owner. Auth’s local synthetic TryCuevo flow consumes it after server verification; this helper itself grants no access or testing exception.

The integrated Providers keeps the current account admission continuation hold and route/child-scoped notices. A hold suppresses premature membership verification, clears prior membership, and resumes normal authorized verification only after balanced release. It supplies no role, session or access and does not bypass API/database checks.

CommandForm captures a deep clone of the original command and its binary receipt validator before awaiting either a new send or original-key retry. The public validator receives receipt and originalCommand; remount, newer draft, actor/key replacement and validation failure cannot substitute a body or settle another key. Validation may run after unmount; callbacks, working-input removal and announcements remain mounted/current-scope effects. Any validator exception retains the original key as an uncertain receipt.

CommandForm defaults to its existing visible h3 title. A parent that already supplies that exact action as its page heading can explicitly set `showHeading={false}` to omit only the duplicate visual heading. This is independent of `asRegion`: title/regionLabel, fields, notes, native validation, draft/journal scope, original receipt checks, callbacks and saved announcement remain unchanged. Actual form/Curriculum configuration browser cases verify both language states, default heading, region identity, unsent input and original retry.

The shared oversized-content error gives file or bounded record-set reduction and school-support guidance in both languages. An HTTP413 does not tell every customer to divide a course. Its render regression preserves uncertain retry and deliberate support-reference behavior.

CommandForm's `command-field-value.ts` converts an absolute retained ISO timestamp into the valid local minute display required by `datetime-local`. This is presentation only: original timezone/seconds/fractions, command body and idempotency key remain immutable for retry. Existing native working values and other field types are unchanged. The actual Admin Guardian journey verifies precise37.321-second payloads, aborted/malformed receipt recovery, valid nonblank retained input, stale revision409 and exact relationship restoration; generic input conversion tests cover malformed/zero/local values.

Paged and bounded-list parsers call the item parser with only its source item. This reconciles canonical `fe04cab` and prevents array index/page contents from being misread as explicit context arguments. Owner parsers still validate selected learner/source scope; paging adds no authority.

`api/client.ts` exposes `CommandJournal.pending()` as a read-only, deeply cloned list of original commands for feature-owned recovery. Features validate their own endpoint/payload before restoring intent; inspecting or changing a returned clone cannot replace a journal entry, settle a key, authorize a retry or expose another actor's state. Session scope changes retain the existing journal-clearing rules. The list is not a second task ledger or customer-facing source catalogue.

CommandForm select values come from the current session draft or retained command, so a temporary empty option list during an authorized source refresh cannot erase the user's selection.
