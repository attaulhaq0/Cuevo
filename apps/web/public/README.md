# Public decorative media boundary

The existing Next.js web application's public directory currently contains documentation only. Authentication uses static imported `studio-background.webp` and `studio-companions.webp` from its feature owner; it serves no public Auth video. The former `media/auth/studio-greeting-writing-alpha-v2.webm` and its empty media folders were removed when the founder chose static artwork.

[Authentication](../features/auth/README.md) owns its real form and static composition. [Asset provenance](../features/auth/assets/README.md) records the active image hashes and the external historical motion pipeline. Shared official branding and current Cuevo learning/role illustrations remain in their imported owners. No duplicate image/video bytes, alternate application or domain package is introduced here.

The [public media decision](../../../docs/decisions/2026-10-03-public-decorative-media.md) retains the accepted Next.js delivery boundary for any separately authorized future public decorative asset. Public bytes must never contain pupil/school records, credentials, private files, provider secrets or arbitrary user URLs. Artwork grants no access, role, academic, curriculum, reward or AI authority. Future asset activation needs explicit source/provenance and packaging evidence; this documentation does not create a placeholder media implementation.

They are historical production evidence, not currently deployed media or proof of Auth/backend/customer acceptance.
