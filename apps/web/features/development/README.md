# Recorded learning recognition

Owns personal recorded XP, source ledger/milestones, explicit admin policy/period/backfill and optional class-period alias leaderboard participation. Public ui.tsx/model.ts/copy.ts; source09/15/39/58/63/80. API owner modules/development. Parent internal queries are excluded. XP uses verified practice/revision/reflection only, never grades/attendance or a composite child score. Unknown/disabled points stay null. School approval and individual opt-in are separate; aliases/tie-safe ranks contain no learner identifiers.

Use shared session/query/form/retry/pagination and semantic tokens. Root composes shell/styles. Unit tests live under test; real source/replay/period/privacy evidence is required before acceptance.

Personal progress includes source15 consecutive recorded days from the current authorized summary, within an explicitly selected recognition period. The latest consecutive UTC day block retains its ending date, all eligible recorded days and verified recognized action count. Period-required, disabled, unobserved and review-required states keep counts/date null. Gaps describe missing authorized records only; this display does not infer effort/ability/character, award XP, change grades or add rankings. The feature parser validates real calendar dates, positive ordered counts and consistent period/state; UI uses shared tokens, localized numbers/dates and English/Arabic copy. recognition-actions browser authoring connects actual learner completion to selected-period one-day readback, mobile RTL and axe; runtime acceptance remains with root.

Policy approval uses the maximum version only after every permitted policy page has been loaded successfully. Unknown pagination/error never becomes version zero. Teachers/admins enter human milestone titles and thresholds; internal milestone keys are generated. Period choices show approved policy version/date, and current points remain recorded-action facts separate from grades.

Leaderboard participation input is scoped to the selected period and remounts when that period changes; a typed alias or opt-in cannot silently become another period's form. The selected period is locked while its command outcome is unresolved. Current owner read failure clears these private working slots; uncertain retries preserve the existing command payload.
`LearnerGoals` lets a student choose a current course, record a planned step and review/close that goal explicitly. Authorized selected-learner staff reads keep school/course labels visible. Goals remain self-reported records, without grade/ability/XP inference or parent disclosure. Source/query errors, revision conflicts and in-memory working input follow shared recovery mechanisms.

The staff learner selector retains every authorized people page through the shared PersonChoice parser and LoadMore. Names include full current class/year labels. It opens personal recorded progress and goal reads only after all pages are known and the selected human context is unique; identical/unknown context requires school-record review instead of opaque ID suffixes. Class choices for period configuration also retain continuation. Development units cover later-page identity, full context, duplicate names and missing class labels; root owns browser/API verification.
