# Progress feature

Owns authorized learner snapshots, observed practice/reflection, factual signals and source-linked support/outcomes. Public interfaces: model.ts, ui.tsx (ProgressWorkspace), copy.ts. It consumes academic native parsers through academic/model and EvidenceDetail/NativeResultView through academic/ui, improvement parsers through improvement/model and read-only OutcomeList through improvement/ui, plus shared query/pagination/session mechanisms. API owner: modules/learner-state; source processor: worker jobs/outbox. Product source IDs 04, 08, 09, 11, 12, 21 and 63.

Feature tests live in test; browser journeys are tests/e2e/learner-state.spec.ts and improvement-loop.spec.ts. Native academic evidence, recorded-only counts, approved support and measured/unmeasured impact remain separate. Active support and measurement ID sets must trace to the supplied source items; measured outcomes retain compatible native baseline/follow-up, threshold, source time and non-causality. Stale habit windows retain real support/outcomes. Unknown is not zero; parents do not receive raw habit, proposal, support or outcome internals. Preserve provenance, time window, keyboard definition-list semantics and RTL.

attention.tsx renders the separate /v1/attention-signals boundary for compatible processed native decline and missing due submissions. Policy version, native/evidence/source facts and uncertainty remain explicit; missing work never becomes a zero grade. Parent queries are excluded. Staff refresh and admin policy controls use explicit supplied versions/confirmation. Parser cases live in test/attention.test.ts and the source77 C/D browser case is tests/e2e/attention-signals.spec.ts.

ReportExport downloads a fresh authorised selected-learner CURRENT_RELEASED_PAGE envelope with coverage NOT_ESTABLISHED. report.ts validates exact learner/native records and escapes all school text into a standalone English/Arabic RTL HTML export. It is a current page, not an official transcript or full coverage claim. Parent exports use the current approved API projection. Tests live in test/report.test.ts and tests/e2e/academic-report.spec.ts.

ClassLearningSummaryPanel serves permitted staff with current-class pages from the shared strict ClassLearningSummary contract. Native numeric/rubric record counts, recorded-only observation windows, support statuses and measured outcomes remain separate with cited source IDs and learner drilldown. Coverage remains NOT_ESTABLISHED; a queried zero count never becomes a zero grade or a complete curriculum assertion. Parents/students do not render this internal class panel. Source18/21/64 apply; browser evidence is tests/e2e/class-learning-summary.spec.ts and the role accessibility matrix.
