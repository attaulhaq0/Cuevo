# Reviewed thinking-focus vocabulary

This private Curriculum-owned artifact defines the six revised cognitive-process identities for reviewed task metadata. The founder authorized this bounded integration in [the thinking-focus specification](../../../../../../docs/superpowers/specs/2026-10-04-reviewed-thinking-focus-bloom.md). It is not an official curriculum pack, learner level, task-difficulty scale, mastery model, prerequisite system or XP policy. Knowledge dimensions and automated classification are outside this version.

`revised-bloom-v1.json` contains Cuevo-authored English/Arabic labels, short original descriptions and learner prompts. The manifest pins its exact SHA-256 bytes and the two captured public research references. University of Florida's guide corroborates the six category identities; Iowa State's current CELT page corroborates the revised framework. The complete Anderson/Krathwohl 2001 edition and Krathwohl 2002 overview are bibliographic anchors, with unavailable full text recorded explicitly. No licence, publisher approval or right to reproduce external tables is claimed. Source capture bytes stay in ignored research history; runtime ships original catalogue metadata only.

`catalogue.ts` validates the exact artifact digest and strict `@cuevo/contracts` schema on every read. `getThinkingFocusCatalogue` and `validateThinkingFocus` are exported through the existing Curriculum `public.ts`; callers must not import private implementation. Source mode resolves the owner-relative JSON. Compiled delivery must copy these private bytes and define the build-time `CUEVO_PEDAGOGY_CATALOGUE_URL` relative to its bundle, following the existing locked-pack build pattern. This is a build constant, not a mutable environment override or caller-provided path.

Every school classification still requires review of actual instructions/materials and rationale through the School Learning authority. The catalogue validates vocabulary, never authorization, publication or official academic applicability. History and source snapshots retain their original task demand and do not update native results or learner state.

Focused tests: `packages/contracts/test/thinking-focus.test.ts` and `apps/api/test/unit/thinking-focus-catalogue.test.ts`. They cover mixed focus, review identity/chronology, exact target/history, read-only bounded snapshots, rejected learner-level fields, immutable catalogue bytes and caller mutation. Actual API/private SQL, built-artifact delivery, parent publication and end-to-end browser acceptance remain separate gates.
