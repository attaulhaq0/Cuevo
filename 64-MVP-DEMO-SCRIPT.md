# Edeviser MVP Demonstration Script

## Audience

Founder, school leaders, teacher, academic reviewer, technical reviewer.

## Demo

### 1. Admin
Create:
- school
- Year 8
- Class 8A
- Mathematics
- teacher
- students
- parents

### 2. Teacher
Create:
- Algebra unit
- lesson
- assessment
- curriculum reference

### 3. Student
Complete activity and assessment.

### 4. Teacher
Review evidence.
Mark.
Give feedback.
Release.

### 5. Edeviser
Show:
- evidence trail
- outcome/attainment state
- development signal
- attention signal

### 6. Intelligence
Teacher selects:
“Analyze this.”

Orchestrator retrieves authorized evidence.

Show:
- observations
- cited evidence
- uncertainty
- recommendation

### 7. Teacher
Approve recommendation.

### 8. Student
Receives personalized practice.

### 9. Development
Show practice/revision observation and XP/achievement.

### 10. Reassessment
Student completes short follow-up.

### 11. Outcome
Show:
baseline → intervention → follow-up → measured change.

### 12. Coordinator
Show:
- class pattern
- intervention outcomes
- basic CQI evidence

### 13. Parent
Show only approved child view.

### 14. Community
Show safe class discussion and optional learning challenge.

## Demo success

The audience should understand:

**Edeviser noticed → explained → recommended → teacher controlled → student acted → system measured.**
